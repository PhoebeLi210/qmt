## 二、第一阶段：K线形态筛选

### 2.1 筛选目标
从全市场股票中筛选出具有上涨动能和特定K线形态的候选股票。

### 2.2 筛选规则（6种形态）

| 序号 | K线形态 | 判定条件 | 预期信号 |
|:----:|---------|----------|----------|
| 1 | **放量上涨** | 收盘价 > 开盘价 AND 成交量 ≥ 5日均量 × 1.3 | 资金入场，涨势确认 |
| 2 | **缩量上涨** | 收盘价 > 开盘价 AND 成交量 < 5日均量 | 惜售待涨，强势信号 |
| 3 | **上涨趋势** | 连续3天收盘价 > 开盘价 AND 价格逐日升高 | 趋势延续看涨 |
| 4 | **触底反弹** | 当日最低价 ≤ 近5日最低价 AND 收盘价 > 开盘价 | 支撑有效，反弹开始 |
| 5 | **低开高走** | 当日开盘价 < 前日收盘价 AND 收盘价 > 开盘价 | 逆势反转，做多意愿强 |
| 6 | **温和放量上涨** | 收盘价 > 开盘价 AND 成交量 ≥ 5日均量 × 1.2 | 资金持续流入 |

### 2.3 筛选结果
- 每天从全市场约5000只股票中，筛选出50-200只候选股票进入下一阶段

### 3.4 综合评分计算公式

```
综合评分 = 基本面得分 × 0.4 + 技术面得分 × 0.6
```

**示例计算**：
```
基本面得分 = 12(PE) + 12(PB) + 8(股本) + 20(行业) + 8(完整) = 60分
技术面得分 = 20(MACD) + 20(均线) + 15(放量) + 15(RSI) + 15(KDJ) + 15(形态) = 100分

综合评分 = 60 × 0.4 + 100 × 0.6 = 24 + 60 = 84分
```

## 八、总结

本系统采用**基本面+技术面**双维度分析框架：

1. **基本面（40%）**：侧重估值合理性和题材热度
2. **技术面（60%）**：侧重资金流向和趋势信号

通过**三阶段筛选**确保推荐质量：
- 阶段一：形态过滤，保留强势股
- 阶段二：深度分析，综合评分
- 阶段三：排序输出，生成理由

**最终输出**：每天最多10只股票的综合推荐清单，包含详细评分和推荐理由。

### A.1 股票分析核心逻辑

```python
def analyze_stocks(self, stocks):
    analyzed_stocks = []
    
    for stock in stocks:
        try:
            # 基本面分析（40%权重）
            fundamental_score, _ = self._analyze_fundamental(stock)
            
            # 技术面分析（60%权重）
            technical_score, positive_indicators, negative_indicators = self._analyze_technical(stock)
            
            # 综合评分计算
            total_score = fundamental_score * 0.4 + technical_score * 0.6
            
            # 检查基本面数据完整性：至少需要有PE或PB数据
            has_pe_or_pb = bool(stock.get('pe')) or bool(stock.get('pb'))
            
            # 通过条件判断
            if total_score >= 10 and positive_indicators and not has_negative and has_pe_or_pb:
                stock['fundamental_score'] = fundamental_score
                stock['technical_score'] = technical_score
                stock['score'] = total_score
                stock['positive_indicators'] = positive_indicators
                analyzed_stocks.append(stock)
            else:
                if not has_pe_or_pb:
                    logger.info(f"股票 {stock['code']} 未通过分析条件：缺少PE或PB数据")
                else:
                    logger.info(f"股票 {stock['code']} 未通过分析条件")
                    
        except Exception as e:
            continue
    
    return analyzed_stocks
```
