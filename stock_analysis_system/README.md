# 股票交易量化系统

一个基于Python的股票交易量化分析系统，可以帮助投资者自动筛选和推荐有投资价值的股票。

## 功能特点

### 1. 数据采集
- 从实时数据源采集全部A股市场股票数据
- 支持深、沪主板股票，科创板，创业板
- 自动去除ST股票
- 数据缓存功能，提高性能

### 2. 股票筛选
- 根据上涨趋势K线形态选取股票
- 根据触底反弹K线形态选取股票
- 支持多种K线形态识别算法

### 3. 数据分析
- **基本面分析**：市盈率(PE)、市净率(PB)、流通股本等
- **技术面分析**：
  - MACD指标（金叉检测）
  - 成交量分析（放量检测）
  - 均线分析（多头排列检测）
  - RSI指标（超卖/超买检测）
  - KDJ指标（金叉检测）
  - 价格形态分析（上涨趋势检测）

### 4. 股票推荐
- 基于综合评分（基本面40% + 技术面60%）
- 最多输出10只推荐购买股票
- 提供详细的推荐理由

### 5. 性能优化
- 数据缓存机制
- 并行处理支持
- 异常处理机制
- 进度跟踪

## 安装环境

### 系统要求
- Python 3.7+
- Windows/Linux/macOS

### 依赖库
- pandas
- numpy
- baostock

### 安装步骤

1. 克隆或下载项目代码
2. 安装依赖库：
   ```bash
   pip install -r requirements.txt
   ```

## 使用方法

### 基本使用

1. 运行主程序：
   ```bash
   python main.py
   ```

2. 查看输出结果：
   - 控制台会显示推荐股票清单
   - 详细日志保存在 `logs/` 目录下

### 配置说明

可以通过修改 `config.py` 文件来调整系统配置：

- **数据采集配置**：调整请求间隔、重试次数等
- **股票选择配置**：调整K线形态识别参数
- **股票分析配置**：调整各项指标的权重和参数
- **推荐引擎配置**：调整最大推荐数量、排序方式等
- **系统配置**：调整线程数、超时时间等

## 扩展功能

### 添加新的数据源

可以在 `data_collector.py` 中添加新的数据源支持：

1. 实现新的数据采集器类
2. 在 `get_all_stocks()` 方法中集成新的数据源

### 添加新的技术指标

可以在 `stock_analyzer.py` 中添加新的技术指标分析：

1. 实现新的指标计算方法
2. 在 `_analyze_technical()` 方法中集成新的指标

### 添加新的K线形态

可以在 `stock_selector.py` 中添加新的K线形态识别：

1. 实现新的形态识别方法
2. 在 `select_by_kline_pattern()` 方法中集成新的形态

## 开发与维护

### 日志查看

日志文件保存在 `logs/` 目录下，可以通过以下命令查看：

```bash
tail -f logs/main_20250101.log
```

### 性能优化建议

1. 增加缓存时间，减少重复请求
2. 使用多线程或多进程加速数据处理
3. 只分析必要的股票数据
4. 优化数据库查询（如果使用数据库）

### 常见问题

1. **数据采集失败**：检查网络连接和baostock账号
2. **推荐股票为空**：可能市场整体趋势不佳，无符合条件的股票
3. **运行速度慢**：增加缓存时间，减少分析周期
4. **指标计算错误**：检查数据格式和计算方法
