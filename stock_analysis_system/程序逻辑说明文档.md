# 股票量化分析系统 - 程序逻辑详细说明文档

## 📋 系统概述

本系统是一个基于多因子量化模型的A股市场股票推荐系统，通过四阶段处理流程（数据采集 → K线形态筛选 → 多因子量化分析 → 推荐生成），从全部A股中筛选出高质量的推荐股票。系统采用严格的数据字段校验（不使用模拟数据与默认值）和多层次因子评估体系，确保推荐结果的科学性和可靠性。

- **推荐数量**：动态确定（根据分析股票总数为 5-15 只），不设固定截断
- **多因子权重**：基本面 30% + 技术面 70%
- **数据原则**：所有评分均基于真实行情数据；数据缺失时保留空值并由数据完整性检查兜底，绝不编造数据

## 🔄 核心处理流程

```
阶段一 数据采集 → 阶段二 K线形态筛选 → 阶段三 多因子量化分析 → 阶段四 推荐生成
```

### 阶段一：数据采集 (Data Collection)
**目标**：获取全部A股市场股票数据（去除ST股票与北交所股票）

**关键特性：**
- **全覆盖采集**：包含沪市主板（600/601/603/605）、深市主板（000/001/002/003）、创业板（300/301）、科创板（688/689）
- **智能过滤**：自动剔除ST股票、北交所等其他板块股票
- **严格数据校验**：不使用模拟数据和默认值，K线不足20个交易日的股票直接放弃
- **动态请求策略**：根据请求次数调整间隔时间（<500次：0.3s → 500-1500次：0.8s → 1500-3000次：1.0s → >3000次：1.2s）
- **实时进度监控**：每100只股票更新一次进度状态

### 阶段二：K线形态筛选 (Pattern Recognition)
**目标**：基于技术形态识别有潜力的股票

**筛选逻辑：**
- **形态识别**：识别两类K线形态
  - `upward_trend`：上涨趋势形态
  - `bottom_rebound`：触底反弹形态（含横盘筑底条件：近10日中至少5日振幅<5%）
- **风险过滤**：剔除明显的技术形态恶化股票

### 阶段三：多因子量化分析 (Multi-factor Analysis)
**目标**：对筛选股票进行基本面、技术面深度分析与风险控制（详见下文评分体系与通过条件）

### 阶段四：推荐生成 (Recommendation Generation)
**目标**：生成最终股票推荐清单（动态数量5-15只，详见阶段四设计）

## 📊 详细数据字段要求

### 必需数据字段清单

**基础信息字段：**
- 股票代码：格式为sh.600000或sz.000001，字符串类型
- 股票名称：字符串类型，用于ST过滤
- 所属行业：字符串类型，用于行业分析和热门题材识别（允许缺失，缺失时为None）
- 所属板块：枚举值，包括沪市主板、深市主板、创业板、科创板

**价格数据字段：**
- 最新价格：浮点数类型，数值必须大于0（否则预筛选淘汰）
- 涨跌幅：浮点数类型，以百分比格式存储（绝对值>50%视为异常，置为None）

**成交量数据字段：**
- 成交量：数值类型，单位为股，必须≥0
- 换手率：浮点数类型，百分比格式，有效范围0%-50%（超出视为异常，置为None）

**基本面数据字段：**
- 市盈率（PE）：浮点数类型（亏损股PE为负值，保留负值参与估值因子评估；解析失败时为None）
- 市净率（PB）：浮点数类型（解析失败时为None）
- 流通股本：数值类型，单位为股
- 总市值：数值类型，单位为元

**技术数据字段：**
- K线数据：每个交易日包含6个子字段
  - 日期（date）、开盘价（open）、最高价（high）、最低价（low）、收盘价（close）：浮点数，必须为正
  - 成交量（volume）：数值，必须≥0
  - 历史数据要求：至少20个交易日的完整有效K线数据，不足则放弃该股票

**形态识别字段：**
- 技术形态：字符串枚举值，包括：
  - upward_trend：上涨趋势形态
  - bottom_rebound：触底反弹形态

### 数据质量验证标准（严格校验，不使用模拟数据与默认值）
- **价格数据**：K线开/高/低/收价格必须>0，无效行直接剔除
- **成交量数据**：成交量必须≥0；换手率有效范围0%-50%
- **涨跌幅**：绝对值>50%视为异常数据，置为None
- **K线数据**：有效K线不足20个交易日的股票直接放弃采集（返回None），不生成模拟K线
- **基本面数据**：字段缺失或解析失败时保留None（不填充默认值），由分析阶段的数据完整性检查兜底
- **本地兜底**：网络获取股票列表失败时，可从本地`local_stock_list.csv`读取真实股票列表

## 🎯 多因子量化评分体系

### 因子一：基本面分析 (Fundamental Analysis)
**多因子权重：30%** | **最高分：60分**

#### 1.1 市盈率分析 (PE Analysis)
**权重：12分**

系统根据市盈率数值进行估值合理性评估：
- 合理估值区间（0 < PE < 30）：获得满分12分
- 偏高但可接受区间（30 ≤ PE < 50）：获得8分
- 高估值区间（50 ≤ PE < 100）：获得4分
- 不合理估值（PE ≤ 0 或 PE ≥ 100 或缺失）：获得0分

#### 1.2 市净率分析 (PB Analysis)
**权重：12分**

系统根据市净率数值进行估值合理性评估：
- 低估值区间（0 < PB < 2）：获得满分12分
- 合理估值区间（2 ≤ PB < 3）：获得8分
- 偏高估值区间（3 ≤ PB < 5）：获得4分
- 高估值或缺失（PB ≥ 5 或 PB ≤ 0 或缺失）：获得0分

#### 1.3 流通股本分析 (Liquidity Analysis)
**权重：8分**

根据流通股本大小评估股票的流动性和活跃度：
- 小盘股（流通股本 < 10亿股）：流动性适中，获得8分
- 中盘股（10亿股 ≤ 流通股本 < 20亿股）：流动性较好，获得4分
- 大盘股（流通股本 ≥ 20亿股）：流动性相对较差，获得0分

#### 1.4 行业分析 (Industry Analysis)
**权重：20分**

行业分析包含两个层次：基础行业分数和热门题材加分
- 基础行业分数：如果股票有明确的行业分类，自动获得10分基础分
- 热门题材完全匹配：如果股票所属行业匹配当前热门题材（如人工智能、新能源、半导体等），额外获得10分加分
- 热门题材部分匹配：如果股票所属行业与热门题材有部分关键词重叠，额外获得5分加分

#### 1.5 数据完整性分析 (Data Completeness)
**权重：8分**

评估股票数据的完整性和可靠性：
- 数据完整性检查：对市盈率、市净率、流通股本、行业信息四个核心字段进行检查
- 计分规则：每个完整且非空的数据字段获得2分加分
- 最高得分：最多获得8分，即四个核心字段全部完整时达到满分

### 因子二：技术面分析 (Technical Analysis)
**多因子权重：70%** | **11个子项理论合计175分，实际得分封顶100分**

技术面分析基于最近20个交易日的K线数据进行（不足20天有效K线的股票在采集阶段已被放弃）。

#### 2.1 MACD指标分析
**权重：20分** | **触发条件：金叉信号**

- 计算过程：使用12日和26日指数移动平均线计算DIF线，再以9日指数移动平均线计算DEA线
- 金叉信号：当DIF线从下方突破DEA线时形成金叉（前一日DIF < DEA 且当日DIF > DEA）
- 评分标准：出现MACD金叉信号时获得满分20分

#### 2.2 成交量分析 (Volume Analysis)
**权重：15分** | **基准：前5天平均成交量**

- 明显放量：当日成交量是基准值的2倍以上时，获得满分15分，信号"放量"
- 温和放量：当日成交量是基准值的1.3倍以上时，获得10分，信号"温和放量"
- 达到基准值（1-1.3倍）：获得5分，无信号
- 低于基准值：获得0分

#### 2.3 换手率分析 (Turnover Rate Analysis)
**权重：15分** | **最优区间：3%-8%**

- 适中换手率（3%-8%）：获得满分15分，信号"适中换手率"
- 较低换手率（1%-3%）：获得8分，信号"较低换手率"（中性信号）
- 较高换手率（8%-10%）：获得5分，信号"较高换手率"
- 过高换手率（≥10%）：获得0分，信号"过高换手率(需谨慎)"（负面信号，参与一票否决）
- 过低换手率（<1%）或缺失：获得0分，信号"过低换手率"（中性信号）

#### 2.4 趋势强度分析 (Trend Strength Analysis)
**权重：15分** | **基于5日涨幅**

- 强势上涨（5日涨幅≥10%）：获得满分15分，信号"强势上涨"
- 稳健上涨（5日涨幅≥5%）：获得10分，信号"稳健上涨"
- 小幅上涨（5日涨幅≥0%）：获得5分，信号"小幅上涨"
- 5日下跌：获得0分，无信号

#### 2.5 量价配合分析 (Price-Volume Coordination)
**权重：15分** | **理想状态：量价齐升**

基于最近一个交易日的价格变化与成交量变化：
- 量价齐升（价涨量增）：获得满分15分，信号"量价齐升"
- 价升量缩：获得10分，信号"价升量缩"
- 价跌量升：获得5分，信号"价跌量升"
- 量价齐跌（价跌量缩）：获得0分，信号"量价齐跌"（中性信号）

#### 2.6 均线多头排列分析 (Moving Average Analysis)
**权重：20分** | **条件：MA5 > MA10 > MA20**

- 计算过程：分别计算5日、10日、20日移动平均线
- 多头排列条件：5日均线 > 10日均线 > 20日均线，且5日均线比20日均线高出2%以上
- 评分标准：满足多头排列条件时获得满分20分，信号"多头排列"

#### 2.7 RSI指标分析 (RSI Analysis)
**权重：15分** | **14日周期**

- 正常区间（50 < RSI < 70）：获得满分15分，信号"RSI正常"
- 偏低区间（30 < RSI ≤ 50）：获得10分，信号"RSI偏低"
- 超卖区间（RSI ≤ 30）：获得8分，信号"超卖"（反弹机会信号）
- 超买区间（RSI ≥ 70）：获得0分，信号"超买"（负面信号，参与一票否决）

#### 2.8 KDJ指标分析 (KDJ Analysis)
**权重：15分** | **触发条件：K线上穿D线**

- 计算过程：基于9日高低价格区间计算RSV值，再通过指数平滑（周期3）计算K值、D值与J值
- 金叉信号：当K线从下方穿越D线时获得满分15分，信号"KDJ金叉"
- 中性状态（20 < K < 80 且 K < D）：获得5分，无信号

#### 2.9 价格形态分析 (Price Pattern Analysis)
**权重：15分** | **基于5日价格变化**

- 上涨趋势（5日涨幅>5%）：获得满分15分，信号"上涨趋势"
- 小幅上涨（5日涨幅>0%）：获得10分，信号"小幅上涨"
- 趋势向下（连续5个交易日收盘价逐日下跌）：获得0分，信号"趋势向下"（负面信号，参与一票否决）
- 其他（5日下跌但非连续）：获得0分，无信号

#### 2.10 均线偏离度分析 (MA Deviation Analysis)
**权重：10分** | **控制追高风险**

- 计算方法：计算当前收盘价相对5日移动平均线的偏离百分比
- 价格合理（偏离度<5%）：获得满分10分，信号"价格合理"
- 价格小幅偏离（5% ≤ 偏离度<8%）：获得5分，信号"价格小幅偏离"
- 价格偏离过大（偏离度≥8%）：扣5分，信号"价格偏离过大"（负面信号，参与一票否决）

#### 2.11 技术分析口诀分析 (Technical Adage Analysis)
**权重：20分** | **基于8条经典量价口诀，8条口诀全部独立生效**

以最近3天与前3天的平均成交量之比（量比）和平均价格涨跌幅判断量价状态：
- 无量：量比 < 0.5
- 缩量：0.5 ≤ 量比 < 0.7
- 放量：量比 > 1.3
- 上涨：3日价格变化 > 2%；下跌：变化 < -2%；稳定：|变化| ≤ 2%

**8条口诀与评分（口诀得分限制在[-20, +20]区间）：**

| 口诀 | 触发条件 | 分值 | 信号 |
|------|---------|------|------|
| 一、放量上涨，必然回调 | 放量 + 上涨 | +5（谨慎信号） | 放量上涨 |
| 二、放量下跌，必然反弹 | 放量 + 下跌 + 前10日涨幅≤10% | +8 | 放量下跌（负面信号） |
| 三、缩量上涨，继续上涨 | 缩量 + 上涨 | +10 | 缩量上涨 |
| 四、缩量下跌，继续下跌 | 缩量 + 下跌 | -8 | 缩量下跌 |
| 五、放量不涨，顶点已现 | 放量 + 价格稳定 | -10 | 放量滞涨 |
| 六、缩量不跌，底部已现 | 缩量 + 价格稳定 | +10 | 缩量筑底 |
| 七、无量顶下跌，后市会大涨 | 无量 + 下跌 | +15（强积极信号） | 无量顶跌 |
| 八、放量顶下跌，后市调整长 | 放量 + 下跌 + 前10日涨幅>10% | -15 | 放量顶下跌 |

说明：口诀二与口诀八通过"前10日涨幅是否超过10%"区分——前期已大涨后的放量下跌视为筑顶出货（口诀八，负面），否则视为反弹机会（口诀二）。注意"放量下跌"信号同时属于负面信号清单，触发一票否决。

### 因子三：多因子综合评分 (Multi-Factor Composite Score)

**计算公式：**

```
综合评分 = (基本面得分 × 30% + 技术面得分 × 70%)
           × 市场环境因子 × 行业动量因子 × 流动性因子 × 估值因子
           + 技术信号强度加分
```

- **基础评分合成**：基本面分析得分和技术面分析得分按照30%和70%的权重合成
- **因子系数调整**：市场环境、行业动量、流动性和估值四大因子以乘数方式对基础评分进行调整
- **技术信号强度加分**：每个积极技术信号加2分（负面信号与中性信号不计入）
- **评分范围控制**：最终评分限制在0-100分范围内

#### 市场环境因子 (Market Environment Factor)
- 因子范围：0.85-1.15，市场好时加分，市场差时减分
- **真实数据接入**：基于上证指数日K线真实行情计算（详见附录A），不使用随机数或模拟数据
- 数据不可用时兜底为中性值1.0（不调整评分）

#### 行业动量因子 (Industry Momentum Factor)
- 热门行业（1.2倍）：人工智能、新能源、半导体、医药生物、数字经济、云计算、5G、新能源汽车、光伏、风电
- 相关行业（1.1倍）：包含"科技"、"创新"、"智能"关键词的行业
- 普通行业（1.0倍）：其他行业无调整

#### 流动性因子 (Liquidity Factor)
- 中等市值（5亿-20亿股）：1.15倍，流动性最佳
- 小盘股（<5亿股）：1.05倍
- 大盘股（>20亿股）：0.95倍
- 数据缺失：1.0倍（不调整）

#### 估值因子 (Valuation Factor)
- PE合理估值（10-25）或低估值（0<PE<10）：1.1倍
- PE偏高估值（25-40）：0.95倍
- PE高估值（>40）或负估值（亏损，PE≤0）：0.85倍
- PB合理估值（1-3）或破净低估（0<PB<1）：1.1倍
- PB偏高估值（3-5）：0.95倍
- PB高估值（>5）：0.85倍
- 数据缺失：1.0倍（不调整）

### 因子四：风险评估控制 (Risk Assessment & Control)
**风险评分计算：分数越高风险越大，需从总分中扣除**

#### 4.1 价格波动风险 (Price Volatility Risk)
- 涨幅过大风险（|涨跌幅|>8%）：扣15分
- 中等涨幅风险（|涨跌幅|>5%）：扣10分
- 轻度涨幅风险（|涨跌幅|>3%）：扣5分

#### 4.2 换手率风险 (Turnover Rate Risk)
- 过高换手率（>15%）：扣12分
- 较高换手率（>10%）：扣8分

#### 4.3 市值风险 (Market Cap Risk)
- 超大盘股（流通股本>50亿股）：扣10分
- 大盘股（流通股本>20亿股）：扣5分

#### 4.4 负面技术信号风险 (Negative Technical Signal Risk)
- 识别范围：放量下跌、过高换手率(需谨慎)、超买
- 扣分标准：每个负面技术信号扣8分

### 最终评分计算
**计算公式：最终评分 = max(0, 多因子综合评分 - 风险调整扣分)**

系统将多因子综合评分减去风险评估扣分，得到最终评分。如果风险扣分超过多因子评分，则最终评分为0分。

## 📋 筛选通过条件

### 阶段三：多因子量化分析通过条件
股票必须**同时满足**以下三个条件才能进入推荐阶段：

1. **动态评分门槛**：系统根据当前时间动态调整评分门槛
   - 交易时间（周一至周五 9:00-15:00）：门槛为25分，相对较低便于筛选
   - 非交易时间（周一至周五其他时间）：门槛为35分，正常水平
   - 周末时间：门槛为40分，稍高门槛确保质量

2. **负面指标过滤（一票否决）**：只要股票具有任何一项负面技术指标，就被排除
   - 负面指标包括：超买、价格偏离过大、趋势向下、放量下跌、过高换手率(需谨慎)

3. **数据完整性要求**：
   - 基本面数据要求：市盈率、市净率、流通股本、行业信息中至少有一项完整数据
   - 技术指标要求：至少有2个积极技术指标确认（负面信号与中性信号不计入）

## 🛒 阶段四：推荐生成 (Recommendation Generation)

#### 4.1 多维度预筛选 (Pre-filtering)
- **基本数据完整性检查**：最新价格必须大于0
- **价格合理性检查**：涨跌幅绝对值超过20%则跳过，避免极端波动风险
- **换手率合理性检查**：换手率超过30%则跳过，避免过度投机风险

#### 4.2 多维度评分排序 (Multi-criteria Sorting)
按以下优先级排序（元组比较）：
- **主要排序**：最终评分（多因子综合评分减去风险扣分）
- **次要排序**：积极技术指标数量（负面与中性信号不计入），指标越多越好
- **第三排序**：基本面评分
- **第四排序**：技术面评分
- **辅助排序**：流通股本越小越好（避免大盘股流动性风险）

#### 4.3 风险等级分类 (Risk Level Classification)
按照风险评分对股票进行三级分类：
- **低风险股票**（风险评分≤15分）：优先推荐
- **中等风险股票**（风险评分16-30分）：谨慎推荐
- **高风险股票**（风险评分>30分）：最后推荐
- **排序原则**：先低风险，再中等风险，最后高风险，各组内保持多维度排序顺序

#### 4.4 行业分散度控制 (Industry Diversification)
- **分散原则**：单个行业最多推荐3只股票，避免行业集中风险
- **行业识别**：基于股票所属行业信息进行归类统计（行业缺失时归入"未知"）
- **停止条件**：当推荐股票总数达到动态推荐数量（见4.5）时停止筛选

#### 4.5 推荐股票数量确定 (Recommendation Count Determination)
根据实际分析的股票总数（total_analyzed，即通过阶段三分析的股票数量）动态确定推荐数量：

| 分析股票总数 | 推荐数量 |
|------------|---------|
| ≥200只 | 15只 |
| 150-199只 | 12只 |
| 101-149只 | 10只 |
| 恰好100只 | 8只 |
| <100只 | 5只 |

#### 4.6 增强推荐理由生成 (Enhanced Reason Generation)
从多个角度为每只推荐股票生成推荐理由，各部分用中文分号连接：

- **形态分析理由**：触底反弹信号（bottom_rebound）/ 上涨趋势确认（upward_trend）
- **技术面理由**（同类型理由用中文顿号连接，排除负面与中性信号）：
  - MACD金叉 → "MACD指标金叉"
  - KDJ金叉 → "KDJ指标金叉"
  - 含"放量"的信号 → "成交量放大"
  - RSI正常 → "RSI指标健康"
  - 多头排列 → "均线多头排列"
  - 超卖 → "超卖状态存在反弹机会"
  - 含"缩量"的信号 → "缩量整理"
- **基本面理由**：0 < PE < 30 → "估值合理(PE适中)"
- **行业分析理由**：属于热门行业(行业名称) / 相关热门题材(行业名称)
- **综合评分理由**：≥90分"综合评分优秀" / 80-89分"综合评分良好" / 70-79分"综合评分中等偏上"

#### 4.7 风险等级评估 (Risk Level Assessment)
基于风险评估控制（因子四）计算的风险评分进行三级分类：
- **低风险**（0-15分）：价格波动稳定、换手率适中、技术面表现良好
- **中等风险**（16-30分）：部分风险指标偏高，但整体可控
- **高风险**（>30分）：存在较大波动、高换手或负面技术信号，需严格控制仓位

#### 4.8 仓位建议 (Position Sizing Suggestion)
基于风险评分和综合评分（多因子综合评分）的双重评估机制：

| 条件 | 仓位建议 |
|------|---------|
| 风险评分≤10 且 综合评分≥85 | 建议重仓(20-30%) |
| 风险评分≤20 且 综合评分≥75 | 建议中仓(15-20%) |
| 风险评分≤30 且 综合评分≥65 | 建议轻仓(10-15%) |
| 其余情况 | 建议观察(5-10%) |

## 📈 主程序输出 (main.py)

系统主流程依次执行四个阶段后：
1. **控制台输出**：按推荐引擎输出顺序（低风险优先→中等风险→高风险）打印推荐清单，包含价格、涨幅、形态、评分、板块、行业、概念、推荐理由、仓位建议，**不截断数量**

3. **统计汇总**：输出各阶段数量、筛选率、通过率、推荐率与总耗时
4. **风险提示**：报告末尾附带标准风险提示（仅供参考，不构成投资建议）

## 🔧 技术实现细节

### 核心算法
1. **动态阈值调整**：根据交易时间（25/35/40分）动态调整评分门槛
2. **多因子权重分配**：基本面30% + 技术面70%，四大因子乘数式合成
3. **风险评分模型**：价格波动、换手率、市值、负面信号四维风险评估
4. **行业分散算法**：最大3只股票/行业的分散度控制
5. **动态推荐数量**：5-15只，根据分析股票总数确定

### 数据质量保证
1. **严格数据校验**：不使用模拟数据和默认值；字段缺失保留None
2. **异常值处理**：换手率超出0%-50%、涨跌幅绝对值>50%等异常数据过滤
3. **K线数据完整性**：要求≥20个交易日完整有效历史数据，否则放弃该股票
4. **无效行剔除**：K线中价格非正或成交量为负的行直接剔除
5. **市场环境因子**：接入真实上证指数数据，数据不可用时中性兜底，绝不编造数据

## 📎 附录A：市场环境因子真实数据方案

### 设计目标
以真实上证指数行情计算市场环境因子（0.85-1.15），替代随机数/模拟数据。

### 数据源（双数据源 + 兜底）
1. **主数据源**：新浪财经上证指数日K线（akshare `stock_zh_index_daily(symbol="sh000001")`）
2. **备选数据源**：东方财富上证指数日K线（akshare `index_zh_a_hist(symbol="000001", period="daily", start_date, end_date)`，近90天）
3. **兜底策略**：两个数据源均不可用时返回中性值1.0（不调整评分），不使用随机数、不使用模拟数据

### 数据有效性校验
- 数据量校验：至少需要21个交易日收盘价
- 时效校验：指数最后交易日距今超过10天视为过期数据，不使用
- 任一校验不通过则视为"数据不可用"，交由兜底逻辑处理

### 因子计算公式
```
ret5  = 最新收盘价 / 5个交易日前收盘价 - 1
ret20 = 最新收盘价 / 20个交易日前收盘价 - 1
ma20  = 最近20个交易日收盘价均值
pos   = 最新收盘价 / ma20 - 1

s5  = clamp(ret5 / 5%,  -1, +1)
s20 = clamp(ret20 / 10%, -1, +1)
sp  = clamp(pos / 5%,   -1, +1)

综合动量分 = 0.5×s5 + 0.3×s20 + 0.2×sp
市场环境因子 = clamp(1.0 + 0.15 × 综合动量分, 0.85, 1.15)
```

含义：
- 近5日涨幅每达5%记满一档（贡献0.5×0.15=7.5%因子调整）
- 近20日涨幅每达10%记满一档（贡献0.3×0.15=4.5%因子调整）
- 价格站上/跌破20日均线每偏离5%记满一档（贡献0.2×0.15=3%因子调整）

### 缓存与重试机制
- **当日缓存**：同一交易日内因子只计算一次（类级缓存），全部股票复用同一因子值
- **失败重试**：拉取失败后10分钟内不再重复请求（避免逐股请求拖慢分析），期间直接使用中性值1.0，10分钟后自动重试
- **日志记录**：成功时记录因子值、5日/20日涨幅、20日线偏离与数据截止日期；失败时记录警告
